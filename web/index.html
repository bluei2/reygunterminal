      Add your own indicator or strategy

      1. Copy plugins\_template.py to a new name without the leading underscore, e.g. plugins\my_rsi.py
      2. Indicator: write compute(bars, tf, ctx) and return Overlay(lines, levels, markers, zones). It draws on this chart and in REYGUN TERM.
      3. Strategy: write evaluate(ctx) and return a Signal(...). It shows in Signal Center. Alerts only.
      4. Restart SuperChart and switch it on here. If it errors, only that plugin is switched off and the error shows here.

      Accounts

      The master is the MT5 terminal the chart reads from. Every BUY/SELL from SuperChart goes to the master and to each enabled follower with the follower's own fixed lot. SL/TP use the same $ distance from each account's own entry. Moving SL/TP, partial closes and closes on the master are copied to the followers (also when you do it inside MT5).
      Each follower needs its own MT5 installation (its own folder with terminal64.exe), logged in once with "Save password" ticked and Algo Trading ON. Passwords are never stored here.
      Ipapakita ang lahat ng MT5 na bukas sa PC / VPS na ito at kung anong account ang naka-login. Isang click: MASTER o FOLLOWER.
